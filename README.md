# createCV

Generador de currículums profesionales con 20 plantillas premium. Crea, personaliza y descarga tu CV en minutos.

## Empezar

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000)

## Deploy

Haz push a GitHub y conecta el repo a Vercel.

## Features

- 20 plantillas premium
- Exporta a PDF y Markdown
- Personalización: colores, fuentes, espaciado
- Sube tu foto de perfil
- Sin registro, sin límite, datos solo en tu navegador
